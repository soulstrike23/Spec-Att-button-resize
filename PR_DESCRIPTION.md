# Add Large Special Attack

A simple accessibility/QOL plugin to enlarge the *native* special attack orb and
combat tab's special attack bar independently of global interface scaling.

- Changes RuneLite-visible widget dimensions and positions only.
- Preserves the game's native click handlers.
- Does not dispatch clicks, invoke menu actions, attach keybinds, or automate combat.
- Optional combat bar resizing is explicitly marked experimental.
- Saves/restores widget layout modes on shutdown or setting changes.

**Review requested:** Please confirm if enlarging these particular native
clickable widgets is permitted by Plugin Hub guidelines. We would welcome any
changes necessary to meet RuneLite/Jagex policy.

**Testing:** This is an initial unverified implementation and should not be
merged until reviewed and tested on a live RuneLite interface.
